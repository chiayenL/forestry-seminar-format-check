# 專討格式檢查

國立中興大學森林學系碩博士班生物組「專題討論」報告格式檢查工具。

上傳 Word (.docx) 報告 → 自動依專討格式加上 **追蹤修訂** 與 **註解說明** → 下載修訂版，用 Word 逐一接受或拒絕。

- 全部在瀏覽器內處理，檔案**不會上傳**到任何伺服器。
- 只有一個檔案 `index.html`，放在 GitHub Pages 即可使用，免費、免架主機。

## 使用方式

1. 開啟網站，選擇自己的 `.docx`（`.doc` 請先在 Word 另存為 `.docx`）。
2. 按「開始檢查」，下載「原檔名_格式修訂.docx」。
3. 用 Word 開啟 →「校閱」→ 顯示「所有標記」，逐一「接受 / 拒絕」修訂並閱讀註解。

標示「請確認」的項目（如：引用在文獻清單找不到、年份不一致、英文縮寫首次出現未寫全文、缺少結論）只加註解，不會改內容。

## 會檢查的項目

| 類別 | 自動修訂 | 只提醒 |
|---|---|---|
| 版面 | A4、上左右邊界 3 cm、欄間距 1.77 字元 | 內文與文獻分兩欄、頁首文字與日期、頁尾頁碼 |
| 字型段落 | Times New Roman／新細明體、各部分字級與粗體、左右對齊、行距、凸排、與前段距離 0.5 行 | |
| 標點空白 | 全形英數字、半形括號與前後空白、中英標點、多餘空白、數字範圍 1-3、千分位、中文與數字/英文間空格、單位前空格、百分比 | |
| 內文引用 | (Good et al., 2013)、& → and、(王○○，2013)、分號 | 引用與文獻清單比對、多筆引用排序 |
| 學名名詞 | 學名斜體、第二次出現屬名縮寫、專有名詞原文小寫 | 英文縮寫首次出現未寫全文 |
| 題目摘要 | 英文題目大小寫、【摘要】、【關鍵詞】與頓號 | 英文題目用縮寫、摘要分段、作者行 |
| 結構 | | 標題層級 一、(一)、1.、(1)、a.、(a)；前言、結論、引用文獻；結論內不可引用 |
| 圖表 | 「圖 1.」、圖說加「。」、表說不加「。」 | 圖說在圖下、表說在表上、表格上下框線 1.25 pt |
| 引用文獻 | 標題「引用文獻」、西文作者寫法、期刊 卷(期): 頁碼、中文全形「：」與「。」 | 排序、et al.、8 位以上作者、標題大小寫、文末分節 |

自動檢查無法完全取代人工校對；例如「專有名詞原文小寫」遇到機構或標準名稱時請拒絕該修訂。

## 更新格式規則

格式規則寫在 `index.html` 裡（搜尋 `const RULES`）。修改後在 GitHub 網頁上直接編輯並「Commit changes」，約 1 分鐘後網站自動更新。
